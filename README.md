# persona-scheduler

Démo Hackfest 2026 : script fictif illustrant un planificateur de publications.
Aucune automatisation réelle : ce dépôt ne publie rien sur aucune plateforme.

- [`personas.yml`](personas.yml) : 3 personas fictifs (données de démonstration)
- [`scheduler.py`](scheduler.py) : boucle d'exemple qui affiche des heures de publication

Persona fictif, démo « Persona Non Grata ».
